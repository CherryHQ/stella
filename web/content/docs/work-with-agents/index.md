title: Work with Agents
---

Most people use Stella by chatting with a shared agent.

Tell the agent what you want done. Stella gives the agent the right context: your memory, the agent's knowledge, available skills, connected tools, and the current workspace. You do not need to learn the specialist software behind the workflow.

In the Web UI, the agent sidebar is your home base. The Inbox at the top collects work that needs your decision — verdicts, plan approvals, exhausted retry budgets, environment retries, or contract fixes — across all agents. Goals waiting on upstream stay with active work and continue automatically. Below it are your chats with agents and groups, your projects, and recent threads. Each agent has tabs for conversation, goals, memory, and skills so you can move between chat, execution state, and agent configuration without losing context.

Projects open on their goals list first. Use a project when the work belongs to a specific workspace or repository; the project's sessions and files tabs hold the durable project chat and the workspace browser.

Long sessions stay readable: when a conversation outgrows the agent's context window, Stella folds older spans into epoch summaries shown at the top of the transcript. Expand a summary to read what was condensed, or open the original messages behind it.

Use this section to learn how to give goals, continue work across channels, work in groups, and understand how agents remember your preferences.

Start with [Give an Agent a Goal](/docs/work-with-agents/give-an-agent-a-goal).
