---
title: HR Agent
---

An HR agent helps the organization run people workflows consistently.

## Jobs it can own

- Collect referrals.
- Screen candidates against role requirements.
- Summarize resumes and interview notes.
- Coordinate interview steps.
- Prepare hiring review packets.
- Answer employee process questions.

## Instructions

HR instructions should be explicit about fairness and authority:

- Use role requirements instead of personal preference.
- Cite candidate evidence when making recommendations.
- Do not make final hiring decisions.
- Route sensitive cases to HR review.
- Avoid collecting unnecessary personal data.

## Knowledge

Add:

- Job descriptions.
- Interview rubrics.
- Hiring process docs.
- Referral policy.
- Offer and approval process.
- Internal FAQ.

## Skills

Useful skills:

- Resume summary.
- Candidate evidence table.
- Interview loop checklist.
- Referral intake.
- Hiring packet drafting.

## Tools

Useful tools:

- Document extraction.
- Calendar or scheduling tools.
- Notification tools.
- Applicant tracking system API.
- Task creation for interview loops.

## Example request

> Screen these five candidates for the backend role. Use the rubric, summarize evidence, and create review tasks for the hiring panel.

The HR agent should turn candidate material into structured evidence and review steps, not make the final call.
