---
title: 使用 Agent 工作
---

大多数人通过聊天使用 Stella 的共享 Agent。

告诉 Agent 你想完成什么。Stella 会为 Agent 准备正确上下文：你的记忆、Agent 的知识、可用 skills、已连接 tools 和当前工作区。你不需要学习背后的专业软件。

在 Web UI 中，Agent 侧边栏是你的工作入口。它会显示 agents、群组对话、临时聊天、projects，以及需要你处理的 Inbox。每个 Agent 都有对话、任务、记忆、技能和文件等 facet，你可以在聊天、执行状态和工作区文件之间切换，而不会丢失上下文。

Project 默认打开任务列表。当工作属于某个固定 workspace 或仓库时，使用 project；需要项目级持久对话或工作区文件时，再进入 project 的对话和文件 facet。

这一节会介绍如何交付 goal、如何跨渠道继续工作、如何在群组中协作，以及 Agent 如何记住你的偏好。

先阅读[给 Agent 一个 goal](/docs/work-with-agents/give-an-agent-a-goal)。
