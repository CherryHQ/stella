---
title: 使用 Agent 工作
---

大多数人通过聊天使用 Stella 的共享 Agent。

告诉 Agent 你想完成什么。Stella 会为 Agent 准备正确上下文：你的记忆、Agent 的知识、可用 skills、已连接 tools 和当前工作区。你不需要学习背后的专业软件。

在 Web UI 中，Agent 侧边栏是你的工作入口。顶部的 Inbox 汇集跨所有 Agent、需要你做决定的工作——裁决、计划审批、重试用尽、环境恢复重试或契约修订。等上游的目标留在活跃工作里，并会自动继续。下面依次是与 agents 和群组的聊天、projects，以及最近的话题。每个 Agent 都有对话、目标、记忆和技能页签，你可以在聊天、执行状态和 Agent 配置之间切换，而不会丢失上下文。

Project 默认打开目标列表。当工作属于某个固定 workspace 或仓库时，使用 project；项目级持久对话和工作区文件位于 project 的会话和文件页签。

长会话依然可读：当对话超出 Agent 的上下文窗口时，Stella 会把较早的部分折叠成 epoch 摘要，显示在会话顶部。展开摘要可以查看压缩内容，也可以打开摘要背后的原始消息。

这一节会介绍如何交付 goal、如何跨渠道继续工作、如何在群组中协作，以及 Agent 如何记住你的偏好。

先阅读[给 Agent 一个 goal](/docs/work-with-agents/give-an-agent-a-goal)。
