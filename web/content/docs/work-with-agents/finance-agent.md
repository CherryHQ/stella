---
title: Finance Agent
---

A Finance agent helps employees move finance work forward without learning every finance system or policy detail.

## Jobs it can own

- Answer reimbursement policy questions.
- Check receipts and required fields.
- Ask for missing documents.
- Prepare reimbursement packets.
- Flag policy exceptions.
- Create review tasks for finance staff.

## Instructions

Tell the agent what it can and cannot do:

- It can explain policy and prepare materials.
- It can identify missing information.
- It can flag exceptions with cited rules.
- It cannot approve payments.
- It must route exceptions to finance review.

## Knowledge

Add the materials that define your finance rules:

- Reimbursement policy.
- Travel policy.
- Approval matrix.
- Receipt examples.
- Tax or compliance notes.

## Skills

Useful skills:

- Reimbursement completeness check.
- Policy exception summary.
- Receipt extraction.
- Finance review packet drafting.

## Tools

Useful tools:

- File extraction for receipts and PDFs.
- Notification tool for finance review.
- Internal reimbursement API.
- Task creation for multi-step reviews.

## Example request

> I need to reimburse a client dinner. Here are the receipt and attendee list. Check whether this is ready to submit and prepare a finance review packet if needed.

The Finance agent should inspect the materials, compare them against policy, ask for missing information, and create review work instead of pretending to approve the expense.
