---
title: 创建共享 Agent
---

共享 Agent 是 Stella 的核心工作单元。

业务负责人可以为专业工作流创建 Agent，例如财务报销、HR 招聘、工程发布或客户支持。负责人为 Agent 配置 instructions、skills、tools、knowledge 和访问规则。组织成员随后可以像使用专业同事一样使用这个 Agent。

团队也可以把多个 Agent 放进同一个群组对话。群聊使用与单 Agent 对话一致的 transcript 和 composer，并增加群组监控，用于查看成员活跃状态、消息数量和共享上传上下文。需要指定某个成员 Agent 处理当前回合时，直接 @ 它。

如果你负责为团队创建或维护 Agent，请从这一节开始。
