# 管理智能体工具

你可以在 Web UI 中选择某个智能体能使用哪些非核心工具。

## 启用或禁用工具

1. 打开 **设置** -> **智能体**。
2. 选择智能体。
3. 打开 **工具** 标签。
4. 启用或禁用内置工具、插件工具。

变更会立即影响新的智能体运行。工具被禁用后，智能体的运行时工具列表里不会再出现它。

## 核心工具

核心沙箱工具始终可用，不能禁用：

- `bash`

它们属于沙箱边界的一部分。固定这些工具可以避免智能体被配置到无法查看或更新工作区的半残状态。

## MCP 和插件工具

MCP 服务器在 **设置** -> **插件** -> **MCP 服务器** 中管理。智能体的工具标签会显示当前可见的 MCP 服务器，但不会重复提供管理开关。

插件工具会在插件启用后出现在工具标签里。如果你想移除某个插件的全部能力，请到插件设置页禁用该插件。
