---
title: HR Agent
---

HR Agent 帮助组织稳定执行人员相关流程。

## 可以负责的工作

- 收集内推。
- 根据岗位要求筛选候选人。
- 总结简历和面试记录。
- 协调面试步骤。
- 准备 hiring review packet。
- 回答员工流程问题。

## Instructions

HR instructions 必须明确公平性和权限边界：

- 使用岗位要求，而不是个人偏好。
- 推荐候选人时引用证据。
- 不做最终录用决定。
- 敏感情况送 HR review。
- 避免收集不必要的个人数据。

## Knowledge

添加：

- 岗位描述。
- 面试 rubric。
- 招聘流程文档。
- 内推制度。
- Offer 和审批流程。
- 内部 FAQ。

## Skills

有用的 skills：

- 简历总结。
- 候选人证据表。
- 面试流程 checklist。
- 内推进件。
- Hiring packet 起草。

## Tools

有用的 tools：

- 文档提取。
- 日历或排期工具。
- 通知工具。
- 招聘系统 API。
- 为面试流程创建 task。

## 示例请求

> 根据后端岗位 rubric 筛选这五位候选人，总结证据，并为 hiring panel 创建 review tasks。

HR Agent 应该把候选人材料转成结构化证据和 review 步骤，而不是做最终决定。
