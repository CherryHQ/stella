---
title: 财务 Agent
---

财务 Agent 帮助员工推进财务相关工作，而不需要每个人都学习所有财务系统和制度细节。

## 可以负责的工作

- 回答报销制度问题。
- 检查票据和必填字段。
- 请求补充缺失材料。
- 准备报销材料包。
- 标记制度例外。
- 为财务人员创建 review task。

## Instructions

告诉 Agent 它能做什么、不能做什么：

- 可以解释制度并准备材料。
- 可以识别缺失信息。
- 可以引用制度规则标记例外。
- 不能批准付款。
- 必须把例外送给财务 review。

## Knowledge

添加定义财务规则的材料：

- 报销制度。
- 差旅制度。
- 审批矩阵。
- 票据示例。
- 税务或合规说明。

## Skills

有用的 skills：

- 报销完整性检查。
- 制度例外总结。
- 票据信息提取。
- 财务 review packet 起草。

## Tools

有用的 tools：

- 提取票据和 PDF 内容。
- 通知财务 review。
- 内部报销 API。
- 为多步骤 review 创建 task。

## 示例请求

> 我需要报销一次客户晚餐。这是发票和参与人名单。帮我检查是否可以提交；如果需要，请准备财务 review 材料。

财务 Agent 应该检查材料、对照制度、请求缺失信息，并创建 review 工作，而不是假装自己能批准费用。
