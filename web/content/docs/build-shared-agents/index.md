---
title: Build Shared Agents
---

Shared agents are Stella's main unit of work.

A domain owner creates an agent for a professional workflow, such as finance reimbursement, HR hiring, engineering release work, or customer support. The owner gives the agent instructions, skills, tools, knowledge, and access rules. The organization can then use that agent like a specialist coworker.

Use this section when you are responsible for creating or maintaining an agent for a team.
