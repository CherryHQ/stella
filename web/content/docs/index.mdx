Stella is a long-running AI partner for people who want more than a chat agent. Use her as a company teammate, a household manager, a private assistant, or a focused collaborator for writing, coding, research, and operations.

Stella is built for multiple tenants, multiple users, and multiple agents from the start. Each agent can have its own role, tools, skills, schedules, sandbox policy, and workspace. Each user gets dedicated memory with each agent, so Stella can understand different people without collapsing everyone into one profile.

Deploy Stella where you want, use your own model API keys, and talk to her from Telegram, QQ, Feishu, WeChat, the Web UI, or the terminal. Conversations, secrets, memories, and workspaces stay under your control.

## Quick Start

```bash
# Install
brew install CherryHQ/tap/stella

# Start the server — Web UI at http://localhost:25678
stella server
```
