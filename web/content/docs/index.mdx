Stella is a self-hosted AI assistant that remembers every conversation, connects to your favorite messaging channels, and works on your behalf — even when you're not watching. Run it on your machine with your own API keys. Your data stays local.

## Quick Start

```bash
# Install
brew install CherryHQ/tap/stella

# Start the server — Web UI at http://localhost:25678
stella server
```
