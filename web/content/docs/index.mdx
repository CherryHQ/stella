Stella gives every person an AI partner that remembers them, works through trusted tools, and shows up where they already chat.

Use Stella as a teammate at work, a manager for home routines, or a private assistant for personal projects. Each user-agent relationship has its own memory, workspace, tools, schedules, and sandbox boundaries.

Stella is built for multiple tenants, multiple users, and multiple agents from the start. Deploy her where you want, use your own model API keys, and talk to her from Telegram, QQ, Feishu, WeChat, the Web UI, or the terminal.

## Quick Start

```bash
# Install
brew install CherryHQ/tap/stella

# Start the server — Web UI at http://localhost:25678
stella server
```
