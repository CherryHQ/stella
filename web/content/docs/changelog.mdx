## [Unreleased]

> **Breaking:** Webhook channels now authenticate with a capability endpoint instead of a personal access token. An admin activates one endpoint per webhook channel, and Stella discloses a one-time URL that both carries the opaque secret and fixes which user the agent runs as — callers no longer send an `Authorization` header. The previous `POST /webhooks/<channel-id>` route with a Bearer token stops working; activate an endpoint for each webhook channel and re-point callers at the new URL. ([#825](https://github.com/CherryHQ/stella/pull/825), [#773](https://github.com/CherryHQ/stella/issues/773))

### ♻️ Refactoring

- Webhook: replace the token-authenticated route with an owner-bound capability endpoint whose one-time URL is the sole credential, rotatable and revocable from the Web UI. ([#825](https://github.com/CherryHQ/stella/pull/825))

## [0.60.0] - 2026-07-19

> **Breaking:** The deprecated `stella` agent CLI has been removed. Agents now use native tools, and `stellad` is the only Stella binary. Installations running v0.50.x must upgrade manually once (download the archive or reinstall): that release's `stellad upgrade` expects the removed `stella` binary. Later releases self-upgrade normally.

### ✨ Features

- Authentication and integrations: add personal access tokens, an OpenID Connect authorization server, and a scoped MCP HTTP/SSE client. ([#615](https://github.com/CherryHQ/stella/pull/615), [#616](https://github.com/CherryHQ/stella/pull/616), [#617](https://github.com/CherryHQ/stella/pull/617))
- Agents: add native, context-scoped tools for goals, schedules, secrets, OAuth, sharing, Recally, and email; accepted goals can now be saved and scheduled as workflows. ([#632](https://github.com/CherryHQ/stella/pull/632), [#636](https://github.com/CherryHQ/stella/pull/636), [#657](https://github.com/CherryHQ/stella/pull/657))
- Knowledge: introduce facts-backed memory, search-first discovery, structured Reflect review and rollout controls, and Web UI management for Knowledge and active Skills. ([#593](https://github.com/CherryHQ/stella/pull/593), [#610](https://github.com/CherryHQ/stella/pull/610), [#661](https://github.com/CherryHQ/stella/pull/661), [#683](https://github.com/CherryHQ/stella/pull/683), [#732](https://github.com/CherryHQ/stella/pull/732), [#733](https://github.com/CherryHQ/stella/pull/733), [#734](https://github.com/CherryHQ/stella/pull/734))
