---
title: Recally CLI
---

The `stella recally` CLI is the source of truth for Recally command syntax and examples. Before you run or script a Recally command, read that command's help output.

## Start here

```bash
stella recally --help
```

## Articles

```bash
stella recally save --help
stella recally list --help
stella recally search --help
stella recally read --help
stella recally update --help
stella recally delete --help
```

Use `stella recally save --help` before saving from scripts. It shows the current argument order, metadata flags, and examples.

## Feeds

```bash
stella recally feed --help
stella recally feed add --help
stella recally feed list --help
stella recally feed poll --help
stella recally feed remove --help
stella recally feed entry add --help
stella recally feed mark --help
```

Use the feed command help before writing polling or feed-entry processing scripts.

## Digest

```bash
stella recally digest --help
```
