如果你刚开始使用 Stella，从这里开始。

Stella 是一套自托管的共享专业 AI Agent 系统。团队先创建 Agent，为它配置 instructions、skills、tools、knowledge 和记忆策略，然后让组织成员通过聊天和它一起工作。

第一个目标很简单：启动 Stella，创建一个共享 Agent，连接一个渠道，然后给 Agent 一个真实 goal。
