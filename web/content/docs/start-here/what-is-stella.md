---
title: What is Stella?
---

Stella is a self-hosted system for shared professional AI agents.

An organization creates agents for real domains: finance, HR, engineering, operations, research, support, or any workflow where expertise repeats. A domain owner configures the agent with instructions, skills, tools, knowledge, and memory rules. Everyone else works with the agent by chatting and giving it goals.

Stella is not just a chatbot. Chat is the interface, not the product. The product is a set of shared agents that know their job, understand the people they work with, and can turn goals into tracked work.

## What makes Stella different

### Agents are shared coworkers

A Finance agent can help many people with reimbursement policy, invoice checks, budget questions, and approval preparation. An HR agent can help with referrals, candidate screening, interview coordination, and hiring process follow-up.

The agent is created once by a domain owner and reused by the organization.

### Users do not need specialist software

Most people should not need to learn the finance system, recruiting system, or internal toolchain just to move a task forward. They tell the agent what they want done. The agent uses the right memory, knowledge, skills, and tools.

### Work can be tracked

For larger goals, Stella can track explicit tasks, dependencies, blockers, runs, and human review. The team can inspect the task UI instead of reconstructing status from chat. Automatic goal planning is not part of this release; create the child tasks explicitly.

### Memory is personal and controllable

Agents can remember each user separately. They can also use shared user memory when that is the right policy, so multiple agents know your preferences and work in your style.

## When to use Stella

Use Stella when the workflow is conversational at the edge but professional underneath:

- Employees ask a Finance agent to prepare reimbursement materials.
- Recruiters ask an HR agent to screen candidates and manage interview steps.
- Engineers ask an Engineering agent to plan a release, review code, or produce follow-up tasks.
- Researchers ask Recally to track topics, read PDFs, summarize articles, and keep a live reading list.

If the answer is "everyone must learn another specialized app," Stella should probably sit in front of that workflow.
