---
title: Stella 是什么？
---

Stella 是一套自托管的共享专业 AI Agent 系统。

组织可以为真实业务领域创建 Agent：财务、HR、工程、运营、研究、支持，或任何重复出现的专业工作流。业务负责人为 Agent 配置 instructions、skills、tools、knowledge 和记忆策略。其他人通过聊天和 Agent 协作，把 goal 交给它。

Stella 不只是聊天机器人。聊天只是入口，不是产品本身。真正的产品是一组共享 Agent：它们知道自己的专业职责，理解和它协作的人，并且能把 goal 变成可追踪的工作。

## Stella 的不同之处

### Agent 是共享同事

财务 Agent 可以帮助很多人处理报销政策、发票检查、预算问题和审批准备。HR Agent 可以处理内推、候选人筛选、面试协调和招聘流程跟进。

Agent 由业务负责人创建一次，然后由组织复用。

### 用户不需要学习专业软件

大多数人不应该为了推进一件事就学习财务系统、招聘系统或内部工具链。他们只需要告诉 Agent 自己想完成什么。Agent 会使用正确的记忆、知识、skills 和 tools。

### 工作可以被追踪

对于更大的 goal，Stella 可以规划工作、拆分任务、连接依赖、设置验收标准并安排 review。团队可以在任务 UI 查看状态，而不是从聊天记录里拼进度。

### 记忆是个性化且可控的

Agent 可以分别记住每个用户。它也可以在策略允许时使用共享用户记忆，让多个 Agent 都知道你的偏好，并按你的风格工作。

## 什么时候使用 Stella

当工作边缘是对话、底层是专业流程时，就应该使用 Stella：

- 员工找财务 Agent 准备报销材料。
- 招聘负责人找 HR Agent 筛选候选人并推进面试步骤。
- 工程师找工程 Agent 规划发布、审查代码或生成后续任务。
- 研究人员用 Recally 跟踪主题、阅读 PDF、总结文章并维护阅读列表。

如果答案是“所有人都要再学一个专业软件”，Stella 很可能应该站在这个工作流前面。
