---
title: 第一个共享 Agent
---

这个 walkthrough 使用财务 Agent，因为它的形态很清楚：很多人需要帮助，工作是专业流程，而且规则必须一致。

## 1. 选择工作职责

先选择一个 Agent 应该负责的工作。

好的例子：

- 帮员工准备报销申请。
- 检查票据是否符合制度。
- 用普通语言解释报销规则。
- 为财务人员准备 review 材料。

太宽泛的例子：

- 做财务。
- 管理公司。

## 2. 编写 instructions

Instructions 定义 Agent 应该如何工作。

对于财务 Agent，应包括：

- Agent 的角色。
- 它需要遵守的报销制度。
- 它应该向员工询问哪些信息。
- 什么时候升级给财务人员。
- 哪些事情绝不能自己批准。

## 3. 添加 knowledge

添加 Agent 正确回答所需的文档：

- 报销制度。
- 发票和票据要求。
- 差旅规则。
- 审批阈值。
- 已通过和被拒绝申请的示例。

Knowledge 让 Agent 基于组织自己的规则工作，而不是给泛泛的财务建议。

## 4. 添加 skills 和 tools

为重复工作添加 skills：

- 检查报销材料完整性。
- 总结报销包。
- 起草财务 review 说明。
- 请求补充缺失材料。

只有当 Agent 需要在聊天之外行动时，才添加 tools：

- 读取上传文件。
- 通知财务团队。
- 调用内部报销 API。
- 创建人工 review task。

## 5. 共享 Agent

把 Agent 开放给正确用户或渠道。共享 Agent 应该有一个稳定的专业身份，但它可以分别记住每个用户。

员工现在可以说：

> 我需要报销上周五的客户晚餐。这是发票和参与人名单。帮我检查缺什么，并准备提交材料。

Agent 会使用它的 instructions、knowledge、skills、tools 和 memory 推进这件事。

## 6. 工作变复杂时使用任务追踪

如果一个 goal 需要多个步骤，就使用 Stella 的任务系统。Agent 可以规划工作、拆分 task、设置验收标准，并把最终材料送入 review。
