Three figures, in the order you need them. **One pipeline** traces a message from ingest to egress and shows where the accept transaction sits. **Two agents, one message** shows what happens when both are woken by the same message and only one reply can land. **The life of a wake row** is the dispatch-row state machine, with the `turn` frame each state emits.

For the prose version — the problem, the rejected alternatives, and the invariants — see [Group chat with multiple agents](./group-chat-multi-agent).
