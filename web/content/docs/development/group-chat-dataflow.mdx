---
title: Group-chat dataflow
description: Unified optimistic group collaboration pipeline.
---

Web and platform messages follow one pipeline: ingest appends a canonical event, creates an outbox, and wakes every member except the author. Each worker claims its newest wake, applies local triage and server caps, then buffers a turn. Acceptance locks group state and atomically commits a fresh reply or marks a stale result held. Accepted replies create their own outboxes; canonical messages and turn state are broadcast through the group event stream.
