---
title: 群聊数据流
description: 统一的乐观群聊协作流水线。
---

Web 和平台消息使用同一条流水线：ingest 写入 canonical event、创建 outbox，并唤醒除作者外的每位成员。每个 worker 领取最新 wake，执行本地 triage 和 Server cap，然后缓冲 turn。接受事务锁定 group state，原子提交新鲜回复或将过期结果标为 held。已接受回复会创建自己的 outbox；canonical 消息与 turn 状态通过 group event stream 广播。
