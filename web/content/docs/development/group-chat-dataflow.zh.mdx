title: 群聊数据流
description: 乐观群聊协作流水线的三张图。
---

三张图，按你需要的顺序排列。**一条流水线**追踪一条消息从 ingest 到 egress，并标出接受事务所在的位置。**两个 agent，一条消息**展示两者被同一条消息唤醒、而只有一条回复能落地时会发生什么。**一条 wake 行的一生**是 dispatch 行的状态机，标注了每个状态发出的 `turn` 帧。

文字版本——问题、被否决的替代方案、以及不变量——见[多 Agent 群聊](./group-chat-multi-agent)。
