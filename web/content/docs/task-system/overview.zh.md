---
title: 目标概览
---

目标用于需要被追踪、迭代执行的成果，而不是只需一条聊天回答的请求。

**目标**是 Agent 推动至验收的一个成果。它带着意图（「完成」意味着什么）、验收契约（系统如何检查产物）以及每一次尝试的记录。目标是递归的：

- **根**目标就是你想达成的成果。
- **子**目标是它拆解出来的子项。
- 每个目标要么是**叶子**（leaf，由 worker 直接执行），要么是**复合**（composite，先规划成子项）。

## 完成是推导的，不是声明的

Agent 从不把目标标记为「完成」。它提交**证据**（evidence，也就是它产出的工作），由系统按目标的**验收契约**检查这些证据：

- **检查**（check）自动运行（命令正常退出、文件存在、测试通过），系统读取结果。
- **评判**（judgment）让 Agent 或人按 rubric 做出决定并记录裁决。

如果契约通过，目标变为**已验收**，其产物被冻结，供依赖它的工作使用。如果不通过，差距会作为下一次尝试的输入。这正是你要在一开始就写清完成标准的原因——它就是工作被衡量的尺子。

## 收敛循环

叶子目标以有界的返工循环运行，而不是一次性执行：

1. 依赖满足 → 目标变为**进行中**。
2. Agent 在一次性内部执行 session 里工作并提交证据。
3. 系统按验收契约评估；确定性检查在同一个 sandbox session 里运行，所以命令能看到 Agent 刚刚使用的文件和环境。
4. 通过 → **已验收**。未通过 → 差距成为下一次尝试的输入——这就是返工。
5. 尝试次数用尽 → **已阻塞**，你可以重试、在时间线补充人工指引，或放弃它。

每次尝试都会保留，但 Web UI 把执行 session 当作内部实现细节。目标**时间线**才是给人看的记录：第 1 次尝试产出 X，验收发现差距 Y，你补充指引 Z，第 2 次尝试通过。

## 生命周期状态

目标会经过：

- **草稿** — 已创建，尚未激活。
- **就绪** — 在依赖和调度满足后可运行。
- **进行中** — Agent 正在处理。
- **已阻塞** — 因等待你的裁决、依赖失败、预算用尽、环境不可用或契约冲突而暂停。
- **待验收** — 已提交证据，等待评判裁决。
- **已验收** — 验收契约通过。（推导得出，终态。）
- **已否决** — 关闭且无返工路径。
- **已放弃** — 你彻底放弃了它。
- **已取消** — 你停止了它。

## 拆解

复合目标不能直接运行——必须先规划成子项。先编写一份拆解（也就是 plan：子目标以及它们之间的依赖），再根据审核策略自动接受或等待你批准。一旦接受，子项被生成，每个子项各自运行收敛循环。

> **状态。** 新建目标现在会自动规划：Stella 会把根目标拆解成可验证的子目标，并交给调度器执行。使用人工审核策略时，Stella 会先把目标停在 Tasks UI 中等待批准，再生成子目标。

当所有必需子项都已验收，父目标会运行**自己的**验收评估——和每个目标一样的关卡，只是作用在根上。没有单独的「最终综合」步骤；它从递归中自然得出。

## 依赖关系

依赖关系让执行顺序可见，并把**已验收产物**向下游传递——只有当上游兄弟项被验收后，子项才能看到它的产物。

适合添加依赖的场景：

- 一个目标需要另一个的已验收产物。
- 上游失败时，下游目标应该停止。
- 你希望就绪视图准确解释还有什么在等待。

硬依赖失败会阻塞下游目标，直到你带理由豁免它。依赖阻塞不能从下游目标直接重试，因为下游输入并没有变化。

## 审核与评判

有些成果应该停下来等待人类决定。把它们交给一个 `human` 权限的**评判**项，用于：

- 制度例外。
- 候选人推荐。
- 发布审批。
- 面向客户的回复。
- 任何会改变金钱、权限或声誉的事情。

评判裁决同样以**证据**形式记录——一条带理由、范围和权限的批准——而不是手动翻转状态。系统据此推导验收结果。

## 目标界面

聊天记录不是好的项目管理工具。在 Web UI 中，打开某个 Agent 后进入**目标**页签，就能在同一处查看根目标、定时工作及其子项。Project 页面也会先打开它的目标列表。

打开一个复合目标会进入**工作流画布**。画布把计划、子目标、依赖边和最终验收放在同一条流里：绿色边表示依赖已满足，动画入边指向正在运行的工作，警示描边表示需要处理的节点。

点击节点会打开详情弹窗：

- **计划** — 根目标意图、概览字段和计划修订。
- **子目标** — 状态、意图、依赖、尝试、就绪状态，以及需要你裁决时的表单。复合子目标会链接到自己的画布。
- **验收** — 契约编辑器、验收记录，以及完成后的已验收产物。
- **时间线** — 从页头按钮打开，包含计划事件、尝试、验收结果、生命周期变化和你的留言。

弹窗状态可以分享：`?node=plan`、`?node=accept`、`?node=activity` 或 `?node=<child-id>` 会直接打开对应弹窗。叶子目标没有画布，页面直接显示尝试列表，并在页头提供同样的验收和时间线弹窗。

**需要你处理**列表只显示有人类恢复动作的阻塞。等上游的目标留在**活跃工作**里，上游完成后会自动继续。

阻塞卡片会显示一行原因，并只给有用动作：

- **环境不可用** — 标记环境已修复并重试，或报告管理员。
- **契约冲突** — 编辑验收契约。
- **预算用尽** — 重试，或放弃它。
- **等上游** — 显示在活跃工作里；重试按钮会隐藏。

当目标因等待你而阻塞时，它的页面会显示需要什么——提交裁决、审阅计划、修订契约，或在时间线补充指引。若该阻塞可重试，Agent 会带着你的输入继续。

实用规则：用聊天描述成果和决策；用目标追踪执行。
