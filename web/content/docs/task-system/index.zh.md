---
title: 交付物
---

**交付物**（deliverable）是你交给 Agent、推动至验收的一个成果——它不是一条聊天回复，而是会跨越单条消息、被持续追踪的工作。

当一个成果需要多次尝试、依赖关系、blocker、明确的「完成」标准或人工签字时，就使用交付物。你描述想要的成果以及验收应该是什么样子；Agent 朝着它推进，系统按验收契约检查产物，并不断返工，直到契约通过。完成状态是从契约**推导**出来的——绝不是 Agent 自己勾选的一个状态。

交付物是递归的：**根**交付物是你的目标，Agent 可以把它**拆解**成各自独立收敛的**子**交付物（sub-deliverable）。
