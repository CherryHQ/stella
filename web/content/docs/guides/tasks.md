title: Background Tasks
---

Stella runs tracked, background work as **goals** — outcomes an agent drives to acceptance, persisted across restarts. This page used to duplicate that model; it now lives in one place.

See **[Goals](/docs/task-system/overview)** for what a goal is, the convergence loop, lifecycle states, dependencies, acceptance, and the Goals surface in the Web UI.

To hand an outcome to an agent, see **[Give an Agent a Goal](/docs/work-with-agents/give-an-agent-a-goal)**.
