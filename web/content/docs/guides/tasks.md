---
title: Background Tasks
---

Stella runs tracked, background work as **deliverables** — outcomes an agent drives to acceptance, persisted across restarts. This page used to duplicate that model; it now lives in one place.

See **[Deliverables](/docs/task-system/overview)** for what a deliverable is, the convergence loop, lifecycle states, dependencies, acceptance, and the Deliverables surface in the Web UI.

To hand an outcome to an agent, see **[Give an Agent a Goal](/docs/work-with-agents/give-an-agent-a-goal)**.
