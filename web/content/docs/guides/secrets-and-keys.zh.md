---
title: 密钥管理
---

## 保险库的作用

Stella 的保险库安全存储你的 API 密钥、令牌和其他机密信息。数据在存储时加密。密钥不会自动注入代理会话，除非你显式绑定到代理、项目，或标记为始终注入。

## 设置

使用保险库前，你需要生成一个主加密密钥并提供给 Stella。

### 1. 生成主密钥

```bash
stellad vault keygen
```

这会打印一个私钥。复制以 `AGE-SECRET-KEY-1` 开头的那一行。`stellad vault keygen --help` 是引导参数的权威来源。

### 2. 使用密钥启动 Stella

```bash
export STELLA_VAULT_KEY="AGE-SECRET-KEY-1..."
stellad server
```

> **请备份你的主密钥。** 如果丢失，所有存储的机密信息将永久无法恢复。请将其保存在密码管理器或其他安全位置。

这就是全部设置。当新用户加入时，Stella 会自动处理每个用户的加密。

## 添加机密信息

### 从Web UI

1. 打开Web UI，进入凭据页面。
2. 在保险库部分选择密钥适用范围。
3. 输入密钥名称（例如 `GITHUB_TOKEN`）和对应的值。
4. 点击保存。

密钥值为只写模式——保存后，明文不会再在Web UI中显示。你可以看到密钥名称列表，但看不到它们的值。

### 密钥范围

密钥可以应用在四个范围：

| 范围                  | 谁可以设置 | 何时可用                 |
| --------------------- | ---------- | ------------------------ |
| 我的凭据 · 所有代理   | 你         | 你使用任意代理时         |
| 我的凭据 · 指定代理   | 你         | 你使用选中的代理时       |
| 管理员凭据 · 系统范围 | 管理员     | 任意用户使用任意代理时   |
| 管理员凭据 · 指定代理 | 管理员     | 任意用户使用选中的代理时 |

多个范围定义同名密钥时，Stella 让最具体的个人密钥胜出：你的指定代理密钥覆盖你的所有代理密钥，后者覆盖管理员指定代理密钥，后者覆盖管理员系统范围密钥。

### 从聊天会话

你也可以在对话中直接存储机密信息。当 Stella 需要一个她没有的密钥时，她会要求你提供。使用 config 命令发送：

```
/config SECRET_NAME your-secret-value
```

这会直接将值写入你的保险库，不会暴露在对话历史中。密钥存储后，Stella 会自动继续你的任务。

你还可以让 Stella 管理你的机密信息：

- **"列出我的保险库密钥。"**
- **"删除 GITHUB_TOKEN 密钥。"**

## 在会话中使用机密信息

当代理会话启动时，Stella 只会解密并注入匹配该会话的密钥：始终注入的密钥、绑定到当前代理的密钥，或绑定到当前项目的密钥。名为 `GITHUB_TOKEN` 的已绑定密钥在会话中可以通过 `$GITHUB_TOKEN` 访问。

未绑定的密钥不会进入会话环境。单条命令需要时，代理可以在 Bash 工具的 `secrets` 参数中声明密钥名称；Stella 只把值注入该命令的子进程，并记录包含密钥名称和截断命令的审计行，不记录值。在 Web UI 中添加非敏感描述，帮助代理判断何时声明。使用 Web UI 查看最近的声明式使用记录。

群组会话不会收到可声明密钥清单，也不能使用单命令密钥注入。

每次会话都会重新加载机密信息。如果你添加或更新了密钥，更改会在下次会话时生效。

代理会话不会收到 Stella API bearer token。代理使用内置工具访问 Stella 能力，而不是在 sandbox 内调用 HTTP API。

## 密钥命名规则

密钥名称必须遵循以下规则：

- 仅限大写字母、数字和下划线（例如 `MY_API_KEY`）
- 必须以字母开头
- 最长128个字符
- 不能以保留前缀开头，如 `STELLA_`

## 小贴士

- **每个服务一个密钥。** 将 `GITHUB_TOKEN`、`OPENAI_API_KEY` 等类似密钥作为单独的保险库条目存储，并只绑定到真正需要它的地方。
- **密钥在重启后持续存在。** 你只需要设置一次。
- **使用Web UI进行审计。** 凭据页面显示所有密钥名称，方便你查看已存储的内容而不暴露值。
- **通过覆盖来轮换密钥。** 要更新密钥，用相同的名称保存新值——它会替换旧值。
