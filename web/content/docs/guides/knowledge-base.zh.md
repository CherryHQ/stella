title: 知识库
---

## 知识库有什么用

Knowledge Base（知识库）让 Stella 从用户或管理员明确管理的文件中回答问题。当问题可能依赖企业、项目、流程或岗位信息时，Stella 会检索当前可用的文件，并在答案附近引用文件名以及可用的页码或标题。

普通聊天附件不会进入知识库。只有希望文件持续可检索时，才应从知识库页面上传。

## 选择文件的生效范围

Stella 会合并检索当前用户和当前智能体可用的全部范围：

| 管理入口                          | 谁可以使用                     |
| --------------------------------- | ------------------------------ |
| 智能体 → 知识库                   | 你使用当前智能体时             |
| 设置 → 知识库                     | 你使用任意智能体时             |
| 设置 → 知识库 → 系统 · 全部智能体 | 所有已登录用户使用任意智能体时 |
| 设置 → 知识库 → 系统 · 仅此智能体 | 所有已登录用户使用所选智能体时 |

只有管理员可以管理两个系统范围。这四个范围是叠加关系，显示顺序不代表优先级或检索权重。

对于员工数字分身，其他同事也应该能向分身询问的员工上下文，应放在“系统 · 仅此智能体”；只有某个员工自己使用的内容，才放在他的个人范围。

## 上传文件

1. 打开当前智能体顶部的“知识库”，或进入“设置 → 知识库”。
2. 管理员可以选择系统范围，并在需要时选择智能体。
3. 选择一个或多个文件，也可以将文件拖入上传弹窗。
4. 等待本批次上传结束。每个文件独立成功或失败。

目前支持 PDF、DOCX、Markdown 和纯文本文件，单个文件最大 25 MiB。

## 理解文件状态

- **解析中**：原文件已经保存，Stella 正在解析。
- **可用**：文件可以被知识库检索命中。
- **失败**：文件没有形成可用的检索内容，列表中会显示经过清理的错误信息。

页面不会自动轮询状态。需要查看最新状态时，请刷新整个浏览器页面。

当前版本中的文件不可直接修改。更新内容时，先上传新文件，等待它变为可用，再删除旧文件。删除文件后，原文件和对应的可检索内容会立即移除。

## 存储额度

| 额度池                                | 文件数 | 原文件总大小 |
| ------------------------------------- | -----: | -----------: |
| 每个用户的个人知识，合计全部个人范围  |  2,000 |       10 GiB |
| 系统 · 全部智能体                     |  4,000 |       20 GiB |
| 系统 · 仅此智能体，每个智能体独立计算 |  1,000 |        5 GiB |

解析中、可用和失败文件都会占用额度，删除文件后立即释放。

## 当前版本暂不支持

当前版本不提供文件预览、下载、原位替换、手动重试解析、光学字符识别，也不支持从飞书等外部来源同步。文件知识库只在有已登录用户和明确智能体的一对一会话中检索，不向群聊或后台任务开放。
