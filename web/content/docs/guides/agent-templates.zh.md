---
title: 代理模板
---

Stella 内置了预设的代理模板，让你可以在几秒钟内创建专用代理。每个模板都附带推荐模型和为特定工作流调优的个性。

## 什么是模板？

模板是创建新代理的起点。你不需要从零开始配置所有内容，只需选择一个模板，就能得到一个已经设置好个性、推荐模型和相关技能的代理。

从模板创建代理后，代理是完全独立的。你可以自定义任何内容——模板只是起点。

## 可用模板

Stella 包含以下内置模板：

| 模板           | 适用场景                             |
| -------------- | ------------------------------------ |
| **Default**    | 通用助手——适合日常对话和任务         |
| **Coder**      | 软件开发——实现、代码审查、调试       |
| **Researcher** | 调查与分析——深度研究、事实核查、对比 |
| **Writer**     | 长文写作——撰写文档、文章、报告       |

每个模板都包含一个个性（称为"灵魂"），用于塑造代理的沟通方式。Coder 直接且注重实现。Researcher 全面且有条理。Writer 注重清晰和结构。

## 从模板创建代理

1. 打开Web UI。
2. 进入**代理**，点击**添加代理**。
3. 你会看到可用模板的网格以及"从空白开始"选项。
4. 选择一个模板。
5. 表单会预填模板推荐的模型和个性。
6. 根据需要调整字段——名称、模型、系统提示——或保持默认值。
7. 保存代理。

新代理立即可用。

## 自定义代理

创建后，代理的每个方面都可以修改：

- **名称和描述** -- 取一个适合你工作流的名称。
- **模型** -- 随时切换到不同的模型或提供商。
- **系统提示** -- 编辑个性和指令以匹配你的需求。
- **技能** -- 添加或移除代理可以使用的技能。

更改在下一次对话时生效。已有的聊天记录会保留。

## 子代理

Stella 还包含专门的子代理来处理委派的工作。当你的主代理需要帮助处理特定任务时，它可以将工作交给子代理：

| 子代理         | 角色                 |
| -------------- | -------------------- |
| **Coder**      | 编写和编辑代码       |
| **Researcher** | 收集信息和分析来源   |
| **Reviewer**   | 审查代码或文档的质量 |
| **Writer**     | 起草和编辑文字内容   |

子代理在后台工作——你的主代理会在适当时自动委派给它们。你不需要配置它们，但可以通过在项目的 `.agents/agents/` 目录中放置覆盖文件来自定义它们的行为。
