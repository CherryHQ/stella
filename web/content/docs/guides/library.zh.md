---
title: 知识库
---

你可以用知识库为 Stella 提供长期参考资料。当对话需要这些内容时，智能体会自行检索。只有从知识库页面明确上传的文件才会进入知识库，普通对话附件不会被自动加入。

## 选择知识的使用范围

每个文件属于以下四种范围之一。你与某个智能体对话时，Stella 会叠加检索同时适用于当前用户和当前智能体的范围。

| 范围              | 谁可以管理 | 何时可用                 |
| ----------------- | ---------- | ------------------------ |
| 我的 · 全部智能体 | 当前用户   | 你使用任意智能体时       |
| 我的 · 仅此智能体 | 当前用户   | 你使用指定智能体时       |
| 系统 · 全部智能体 | 管理员     | 任意用户使用任意智能体时 |
| 系统 · 仅此智能体 | 管理员     | 任意用户使用指定智能体时 |

在 **设置 → 知识库** 中管理“我的 · 全部智能体”。管理员还可以在这里选择两个系统范围。要管理“我的 · 仅此智能体”，请打开对应智能体的档案页并选择 **知识库**。

四种范围是叠加关系，排列顺序不代表检索优先级。个人范围里的文件只属于上传者；系统范围里的文件可以为其他用户的对话提供知识。

## 上传文件

1. 打开目标范围对应的知识库页面。
2. 如果选择“系统 · 仅此智能体”，先选择目标智能体。
3. 点击 **上传文件**，选择一个或多个文件。
4. 查看每个文件的上传结果，之后刷新页面即可获取最新处理状态。

知识库 V1 支持纯文本（`.txt`）和 Markdown（`.md`、`.markdown`）文件，单个文件最大为 25 MiB。批量选择时，每个文件会独立上传；其中一个失败不会取消其他文件。

## 理解处理状态

- **处理中** — 文件正在排队或解析，暂时不能检索。
- **可用** — 文件可以被适用范围内的智能体检索。
- **失败** — 解析未完成，文件不能参与检索。请查看页面中的错误信息，删除文件后上传修正版本。

当智能体判断当前问题可能需要相关资料时，Stella 会自动检索知识库；开始对话前不需要指定某篇文档。

## 配额

| 范围或配额池                                           | 文件数量上限 | 原文件容量 |
| ------------------------------------------------------ | -----------: | ---------: |
| “我的 · 全部智能体”与该用户所有“我的 · 仅此智能体”合计 |        2,000 |     10 GiB |
| 系统 · 全部智能体                                      |        4,000 |     20 GiB |
| 每个“系统 · 仅此智能体”范围                            |        1,000 |      5 GiB |

页面显示的是对应配额池的总用量。删除文件后，逻辑配额会立即释放。

## 查找和删除文件

搜索框会按文件名筛选当前范围。文件较多时，列表会分页显示；点击 **加载更多** 查看下一页。

删除后，文件会立即停止参与检索，并且无法恢复。如果要更新文件，建议先上传新版本，等新版本变为 **可用** 后再删除旧版本。

第一方 API 客户端通过 `page_size` 设置分页大小，并把上一页返回的不透明 `next_page_token` 作为下一次请求的 `page_token`。当 `next_page_token` 为 `null` 时表示已经到达末页；客户端不应解析或修改分页令牌。
