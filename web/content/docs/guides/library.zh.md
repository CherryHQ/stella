title: 知识库

## 知识库用来做什么

知识库为 Agent 提供持久的参考资料，适合存放企业制度、岗位流程和个人工作文档。当当前对话需要这些依据时，Stella 会检索知识库，并在回答中标出来源文件。

知识库文件和普通对话附件不同。把文件附在一次对话里，不会自动加入知识库。只有从知识库页面明确上传的文件才会变成可检索资料。

单个文件最大 25 MiB，暂不从云盘或其他外部来源同步文档。

支持上传以下格式：

| 类型         | 扩展名                                                                                        |
| ------------ | --------------------------------------------------------------------------------------------- |
| 文档         | `.pdf`、`.doc`、`.docx`、`.odt`、`.rtf`                                                       |
| 表格         | `.xls`、`.xlsx`、`.ods`、`.csv`、`.tsv`                                                       |
| 演示文稿     | `.pptx`                                                                                       |
| 网页与电子书 | `.html`、`.htm`、`.xhtml`、`.epub`、`.fb2`                                                    |
| 文本与数据   | `.txt`、`.md`、`.markdown`、`.mdx`、`.rst`、`.org`、`.json`、`.yaml`、`.yml`、`.toml`、`.xml` |

Stella 会同时校验扩展名和文件结构。把不支持或已损坏的文件改成上述扩展名，不能使其通过上传。扫描页面目前还不能读取，光学字符识别会作为独立能力接入。

旧版 `.ppt` 与 `.odp` 暂不开放，因为 Xberg 1.0.14 还不能提供可靠幻灯片引用所需的逐页范围。

## 文件在哪些范围生效

每个文件属于以下四个范围之一。检索时会把四个可用范围叠加起来，而不是按优先级覆盖。

| 范围              | 谁来管理 | 何时可用                  |
| ----------------- | -------- | ------------------------- |
| 我的 · 全部智能体 | 当前用户 | 该用户使用任意 Agent 时   |
| 我的 · 仅此智能体 | 当前用户 | 该用户使用指定 Agent 时   |
| 系统 · 全部智能体 | 管理员   | 所有用户使用任意 Agent 时 |
| 系统 · 仅此智能体 | 管理员   | 所有用户使用指定 Agent 时 |

在 **设置 → 知识库** 中管理“我的 · 全部智能体”文件。管理员在 **管理控制台 → 部署资源 → 全局知识库** 中管理两个系统范围。在某个 Agent 的 **知识库** 页面中，管理自己只供该 Agent 使用的文件。

## 上传和处理状态

上传后，文件会经历以下状态：

- **处理中**：Stella 正在解析并建立索引，此时还不能检索。
- **可用**：已发布的文件片段可以被检索。
- **失败**：解析没有完成，页面会显示失败状态。

刷新浏览器即可获取最新状态。再次上传相同内容会创建另一份知识库文件，不会悄悄覆盖已有文件。

删除文件后，它会立即退出检索；Stella 随后在后台清理原文件和解析产物。

## Agent 如何使用知识库

你只需自然提问，不需要先指定文件，也不需要写检索命令。Agent 会自行判断问题是否需要知识库依据，并结合当前对话生成检索词，再返回最相关的内容片段。

每次检索只覆盖当前用户和当前 Agent 可用的四级范围。Stella 会在同一条数据库检索中同时过滤权限、发布状态和删除状态，再按相关性返回完整的命中文本片段，而不是把整份原文件交给模型。

回答使用知识库内容时，请核对文件名引用，以及可用的页码、幻灯片、工作表行范围或结构标题。来源文档只作为参考资料，其中的文字不能覆盖当前对话要求或 Stella 的安全规则。

群聊目前不启用知识库检索。只要一次一对一的 Agent 运行保留了可信的用户和 Agent 身份，它就可以在 Web、支持的私聊渠道、Webhook、定时任务、任务、Workflow 和委托执行中使用知识库。

## 知识库和记忆的区别

知识库用于你明确维护、希望长期作为资料检索的文档；记忆用于保存某个人的持续上下文和历史对话。对话中出现的文件或事实不会自动进入知识库，上传知识库文件也不会改写 Agent 的记忆。
