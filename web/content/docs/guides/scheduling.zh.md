## 任务模板

部分定时任务由平台提供模板——预先配置好的提示词，代表你执行特定任务。这些任务不会自动对所有人运行，而是采用订阅制：你主动订阅一个模板，它就成为你自己的定时任务。你可以像管理其他任务一样修改频率、暂停或删除它。

可用模板：

- **recally-rss** — 轮询你的 Recally feeds 并保存新条目，默认每 6 小时执行一次。
- **recally-digest** — 根据你保存的文章和 feeds 生成阅读摘要，默认每 24 小时执行一次。

### 通过 Web UI 订阅

1. 打开任意 Agent，进入**目标**页签。
2. 点击 **New Schedule**（新建定时任务）。
3. 在 sheet 顶部选择 **From template**（从模板创建）。
4. 选择一个模板卡片。已订阅的模板显示为禁用状态。
5. 可选择修改频率（间隔或 cron）、Agent 和会话模式。
6. 点击 **Create**（创建）。

订阅后会出现在定时任务列表，并带有模板标识（例如 `订阅 · recally-rss`）。提示词由平台维护且只读——如需自定义提示词，请创建普通定时任务。

### 通过对话订阅

直接让 Stella 创建或移除模板订阅。代理使用原生 scheduler 工具，所以你可以这样说：

- “订阅 Recally RSS 模板。”
- “每 12 小时运行一次 Recally RSS 模板。”
- “取消订阅 Recally RSS 模板。”

### 通过 API 订阅

```
POST /api/agents/{agentId}/scheduler/jobs
{
  "template_key": "recally-rss",
  "every": "12h"
}
```

省略 `every`（和 `cron`）时使用模板的默认频率。使用 `template_key` 时不能同时传 `message`，提示词由平台管理。

每个用户每个模板只允许一份订阅，重复订阅返回 `409 Conflict`。

## 你可以调度什么

Stella 可以按计划运行任务——提醒、定期检查、自动化报告，以及任何你能用自然语言描述的事情。任务在重启后依然存在，所以一旦设置好，它会持续运行直到你移除它。

有三种调度类型：

- **循环（间隔）** — 每隔 N 分钟/小时运行一次。例如："每30分钟检查一下我的邮箱。"
- **循环（cron）** — 按 cron 表达式运行。例如："每个工作日早上9点，给我总结一下日程。"
- **一次性** — 在指定时间运行一次，然后自动停用。例如："下午3点提醒我给牙医打电话。"

## 自然语言示例

直接告诉 Stella 你想要什么。她会创建正确类型的任务：

- **"每天早上9点提醒我查看任务清单。"**
- **"每小时检查一下我的 RSS 订阅。"**
- **"30分钟后提醒我推送分支。"**
- **"每周五下午5点，总结一下我这周完成了什么。"**
- **"在 2024-12-25T10:00:00+08:00 祝我圣诞快乐。"**

Stella 会将这些翻译成合适的调度类型并为你创建任务。

## 会话模式

每个定时任务都有一个会话模式，控制 Stella 是否记住之前的运行：

- **复用**（默认）— Stella 为任务保持一个持久会话。每次运行都基于之前的内容。适合需要上下文的持续任务，比如监控项目或跟踪每日进展。
- **新建** — Stella 每次从头开始，不保留之前运行的记忆。适合独立的任务，比如天气查询或提醒。

你可以在创建任务时指定模式：

- **"每30分钟检查邮箱，每次重新开始。"** — 使用"新建"模式。
- **"每天晚上总结我的进展，保持对话连续。"** — 使用"复用"模式。

## 管理任务

### 从Web UI

打开某个 Agent 并进入**目标**页签，定时任务会和 goals 一起显示。你可以：

- 查看任务状态、调度计划和上次运行时间
- 启用或禁用任务
- 编辑任务设置
- 删除任务

## 小贴士

- **使用 cron 实现精确定时。** cron 表达式能精细控制：`0 9 * * 1-5` 表示"工作日早上9点"。对于简单的"每隔 N 分钟"模式，使用间隔（`--every`）。
- **一次性任务运行后会自动停用。** 条目会以停用状态保留在列表中，运行历史和“立即运行”仍然可用；不再需要时可以手动删除。
- **监控任务使用"复用"模式。** 如果任务需要持续跟踪某些内容（比如项目进展），复用模式让 Stella 能参考之前运行时看到的内容。
- **与其他功能组合使用。** 定时任务可以使用 Stella 的所有功能——阅读助手、技能、记忆。例如，安排一个任务每天早上检查 RSS 订阅并总结新文章。
