## 你可以调度什么

Stella 可以按计划运行任务——提醒、定期检查、自动化报告，以及任何你能用自然语言描述的事情。任务在重启后依然存在，所以一旦设置好，它会持续运行直到你移除它。

有三种调度类型：

- **循环（间隔）** — 每隔 N 分钟/小时运行一次。例如："每30分钟检查一下我的邮箱。"
- **循环（cron）** — 按 cron 表达式运行。例如："每个工作日早上9点，给我总结一下日程。"
- **一次性** — 在指定时间运行一次，然后自动移除。例如："下午3点提醒我给牙医打电话。"

## 自然语言示例

直接告诉 Stella 你想要什么。她会创建正确类型的任务：

- **"每天早上9点提醒我查看任务清单。"**
- **"每小时检查一下我的 RSS 订阅。"**
- **"30分钟后提醒我推送分支。"**
- **"每周五下午5点，总结一下我这周完成了什么。"**
- **"在 2024-12-25T10:00:00+08:00 祝我圣诞快乐。"**

Stella 会将这些翻译成合适的调度类型并为你创建任务。

## 会话模式

每个定时任务都有一个会话模式，控制 Stella 是否记住之前的运行：

- **复用**（默认）— Stella 为任务保持一个持久会话。每次运行都基于之前的内容。适合需要上下文的持续任务，比如监控项目或跟踪每日进展。
- **新建** — Stella 每次从头开始，不保留之前运行的记忆。适合独立的任务，比如天气查询或提醒。

你可以在创建任务时指定模式：

- **"每30分钟检查邮箱，每次重新开始。"** — 使用"新建"模式。
- **"每天晚上总结我的进展，保持对话连续。"** — 使用"复用"模式。

## 管理任务

### 从Web UI

打开某个 Agent 并进入**任务**页签，定时任务会和一次性 tasks、goals 一起显示。你可以：

- 查看任务状态、调度计划和上次运行时间
- 启用或禁用任务
- 编辑任务设置
- 删除任务

### 从 CLI

```bash
# 列出所有定时任务
stella scheduler list

# 以 JSON 格式列出任务（适合脚本使用）
stella scheduler list --json

# 添加循环任务（间隔）
stella scheduler add --name "email-check" \
  --message "Check my email and summarize new messages" \
  --every 30m

# 添加循环任务（cron）
stella scheduler add --name "morning-briefing" \
  --message "Give me a morning briefing" \
  --cron "0 9 * * 1-5"

# 添加一次性提醒
stella scheduler add --name "dentist-reminder" \
  --message "Remind me to call the dentist" \
  --at "2024-12-15T15:00:00+08:00"

# 添加指定会话模式的任务
stella scheduler add --name "weather" \
  --message "Check today's weather in Beijing" \
  --every 24h \
  --session-mode new

# 移除任务
stella scheduler remove <job-id>
```

## 心跳监控

心跳是一种特殊的调度功能，用于监控系统上的一个文件。你把指令写在 `HEARTBEAT.md` 文件中，Stella 会定期检查它。如果文件有内容，Stella 会读取它，判断是否需要采取行动，然后执行指令。

适用场景：

- 与能写入文件的外部工具集成
- 创建一个 Stella 监控的简易"收件箱"
- 从 cron 任务或 CI 流水线触发 Stella

### 设置心跳

从Web UI配置心跳：

1. 启用心跳监控。
2. 设置轮询间隔（例如每10分钟）。
3. 设置心跳文件的路径（例如 `HEARTBEAT.md`）。

当 Stella 检测到文件中有内容时，她会读取它、执行操作，并通过你配置的通知渠道发送结果。

## 小贴士

- **使用 cron 实现精确定时。** cron 表达式能精细控制：`0 9 * * 1-5` 表示"工作日早上9点"。对于简单的"每隔 N 分钟"模式，使用间隔（`--every`）。
- **一次性任务会自动清理。** 一次性任务运行后会自动从调度中移除。
- **监控任务使用"复用"模式。** 如果任务需要持续跟踪某些内容（比如项目进展），复用模式让 Stella 能参考之前运行时看到的内容。
- **与其他功能组合使用。** 定时任务可以使用 Stella 的所有功能——阅读助手、技能、记忆。例如，安排一个任务每天早上检查 RSS 订阅并总结新文章。
