title: 模型
---

Stella 支持多个 AI 提供商，让你选择哪个模型来驱动对话。你可以随时切换模型，无需重启。

## 支持的提供商

Stella 支持三种类型的提供商：

- **Anthropic** -- Claude 系列模型（Sonnet、Opus、Haiku）
- **OpenAI** -- GPT 和 o 系列模型
- **OpenAI 兼容** -- 任何实现了 OpenAI API 的服务，如 Perplexity、Together.ai 或本地模型服务

你可以同时配置多个提供商，在不同的代理中混合使用来自不同提供商的模型。

## 设置提供商

1. 打开Web UI。
2. 进入**提供商**部分。
3. 点击**添加提供商**并选择提供商类型。
4. 输入你的 API key 和所需设置（例如 OpenAI 兼容提供商的自定义 base URL）。
5. 保存提供商。

保存后，Stella 会自动从该提供商获取可用模型列表。

## 模型层级

Stella 中的每个代理最多使用三个模型层级：

| 层级     | Stella 何时使用                |
| -------- | ------------------------------ |
| **默认** | 日常对话和一般任务             |
| **强力** | 难题、复杂推理、多步骤分析     |
| **快速** | 快速检查、简单查询、轻量子任务 |

如果你只设置了默认模型，Stella 会将其用于所有场景。强力和快速层级是可选的——当你希望 Stella 自动为任务选择合适的模型时再设置。

在Web UI的代理设置页面中为每个代理配置模型层级。

## 视觉模型

视觉模型替那些拿不到图片的模型读图：它转写图中的文字并描述画面内容，再把这段文字交给回答问题的模型。视觉模型不会直接回复你。

与上面的代理层级不同，这是整个部署共用的一份设置：由管理员在 **设置 -> 视觉** 中配置一次。读图属于基础设施，而非个性——没有理由让两个代理对同一张截图给出不同的转写，而按代理配置会让每个新建的代理都默默地看不了图。

### 图片会交给谁

当出现图片时——你在频道里发的照片，或代理打开的图片文件——Stella 按顺序选择第一个适用的：

1. **回答问题的模型本身**，前提是它的 **Input** 模态声明了 `image`。保真度最高，也不多一次调用。
2. **视觉模型**，否则走这一步。
3. **本地文本提取（Xberg）**，在没配视觉模型或视觉模型失败时兜底。它能读出图中的文字，但无法描述照片、图表或版面。

关键在第 1 步：**只有你明确声明了，模型才会拿到图片。** 提供商不会上报模型的模态信息，所以没配过的模型一律是"未声明"，而 Stella 把未声明当作"不接收图片"。把图片塞给一个读不了它的模型，只会得到一个空白占位符，然后代理白白花一轮去绕开它——所以保守的假设才是有用的假设。

要让多模态模型直接拿到图片，去 **设置 -> 提供商**，编辑该模型，把 **Input** 设为 `text, image`。

这条链不会回退到代理的默认模型：那正是没拿到这张图的模型。

## 切换模型

你可以在对话中切换模型而不丢失上下文：

- **在任何频道中** -- 输入 `/model` 查看可用模型并选择其他模型。在 Telegram 上会显示内联键盘方便快速选择。
- **在Web UI中** -- 进入**模型**页面浏览可用模型并切换当前模型。

切换会在下一条消息时生效。
