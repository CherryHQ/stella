---
title: Telegram 机器人
---

stella 包含一个通过长轮询运行的 Telegram 机器人 —— 无需 webhook 或公网 IP。

## 设置

1. 通过 [@BotFather](https://t.me/BotFather) 创建一个机器人并记录 bot token
2. 运行 `stella --open` 启动管理面板
3. 在管理面板中：添加一个 AI 提供商，然后使用你的 bot token 配置 Telegram 频道
4. 启动网关：

```bash
stella
```

所有频道配置（token、群组模式、允许的 ID 等）都通过管理面板管理。环境变量仅限于提供商 API 密钥（`ANTHROPIC_API_KEY`、`OPENAI_API_KEY`）和 `STELLA_HOME`。

## 多用户支持

每个 Telegram 用户会从其平台身份自动解析。会话按用户和代理分别管理，会话键的格式为 `{agentID}:tg:{userID}:{context}`。无需手动设置用户。

## 代理切换

`/agent` 命令允许用户在可用的代理之间切换：

- `/agent` -- 列出所有可用的代理
- `/agent <name>` -- 切换到指定的代理

在私聊中，这会设置用户的默认代理。在群组中，这会设置整个群组的活跃代理。

## 流式响应

机器人实时流式传输 LLM 响应，采用两种策略：

### 私聊：Draft API（Bot API 9.3+）

使用 `sendMessageDraft` 实现流畅的动画流式传输，无需担心速率限制问题。如果 API 不可用，会自动回退到编辑模式。

### 群聊：就地编辑

发送初始消息，并在令牌到达时定期（约每秒）编辑它。流式消息在完成后被删除，然后发送最终响应。

### 工具指示器

在工具执行期间，流式消息会显示带有表情符号的状态指示器：

| 工具     | 表情符号 |
| -------- | -------- |
| `bash`   | 闪电     |
| `read`   | 书本     |
| `write`  | 铅笔     |
| `edit`   | 扳手     |
| `search` | 放大镜   |

## 图片支持

机器人在私聊中接受照片消息。当你发送图片时：

1. 机器人从 Telegram 的文件 API 下载最高分辨率版本
2. 检测 MIME 类型并对图片进行 base64 编码
3. 将其作为多模态消息（图片 + 可选的说明文本）发送给模型
4. 模型分析图片并用文本回复

使用场景：描述截图、分析图表、从照片中读取文档等。

如果模型返回图片（例如来自工具结果），它们会在文本响应后作为 Telegram 照片发送回来。

> **注意：** 图片支持需要支持视觉的模型（例如 Claude 3+、GPT-4o）。

## 文件/文档支持

用户可以向机器人发送文档（PDF、DOCX、XLSX 等文件类型）。收到文档时：

1. 机器人将文件保存到用户的私有 assets 目录
2. 附带 kreuzberg 提取提示传递给 Agent，以便读取文件内容
3. 文档附带的说明文字将作为用户的文本消息一并传入

Agent 随后可使用 `kreuzberg extract` 命令解析文件。

> **注意：** 文件上传需要激活 kreuzberg skill。

## 群组支持

机器人支持群聊，具有可配置的响应行为。在管理面板中设置群组模式：

- `mention` -- 仅在被 @提及时响应（默认）
- `always` -- 响应所有消息
- `disabled` -- 完全忽略群组消息

## 访问控制

通过在管理面板中添加允许的用户 ID 来限制哪些 Telegram 用户可以与机器人交互。留空则允许所有用户。在 Telegram 中使用 `/whoami` 命令获取你的用户 ID。

## 通知

机器人同时作为通知后端。在管理面板中配置默认通知聊天和可选的广播频道。

用于：

- `notify` 代理工具（在网关模式下）
- 调度器任务结果广播

请参阅 [notification-system.md](/docs/features/notification-system) 了解完整的通知架构。

## 模型切换

用户可以通过 `/model` 命令触发的内联键盘在对话中切换模型。模型列表支持分页和文本过滤。

## 命令

| 命令                | 描述                                           |
| ------------------- | ---------------------------------------------- |
| `/start` 或 `/help` | 欢迎和帮助信息                                 |
| `/new`              | 开始新的会话                                   |
| `/compact`          | 压缩对话历史                                   |
| `/model`            | 列出可用模型                                   |
| `/model <number>`   | 按编号切换模型                                 |
| `/model <query>`    | 按名称过滤模型                                 |
| `/agent`            | 列出可用代理                                   |
| `/agent <name>`     | 切换活跃代理（私聊中为用户默认，群聊中为群组） |
| `/whoami`           | 显示你的用户 ID                                |

## 配置参考

以下所有设置都通过 `stella --open` 管理面板管理。

| 字段          | 描述                                      | 默认值    |
| ------------- | ----------------------------------------- | --------- |
| `token`       | Bot API token                             | （必需）  |
| `notify_chat` | 用于主动通知的聊天 ID                     |           |
| `channel_id`  | 广播频道（@name 或数字 ID）               |           |
| `group_mode`  | 群组行为：`mention`、`always`、`disabled` | `mention` |
| `allowed_ids` | 允许使用机器人的用户 ID（空 = 所有人）    | `[]`      |
