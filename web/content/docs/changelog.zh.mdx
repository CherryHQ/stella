## [0.36.0] - 2026-05-22

### ⚠️ 破坏性变更

- **API**：会话、定时任务和用户任务接口已移至 Agent 上下文下。所有端点路径变更如下：
  - `GET /api/sessions` → `GET /api/agents/{agentID}/sessions`
  - `POST /api/sessions` → `POST /api/agents/{agentID}/sessions`
  - `GET/DELETE /api/sessions/{id}` → `GET /api/agents/{agentID}/sessions/{sessionID}`
  - `GET /api/scheduler/jobs` → `GET /api/agents/{agentID}/scheduler/jobs`
  - `POST /api/scheduler/jobs` → `POST /api/agents/{agentID}/scheduler/jobs`
  - `PUT/DELETE /api/scheduler/jobs/{id}` → `PUT/DELETE /api/agents/{agentID}/scheduler/jobs/{jobID}`
  - `GET /api/tasks` → `GET /api/agents/{agentID}/tasks`
  - `POST /api/tasks` → `POST /api/agents/{agentID}/tasks`

  旧的扁平路径端点已移除，无兼容过渡层。请更新所有依赖这些路径的外部集成或脚本。

### ✨ 功能

- **技能**：将技能接口纳入 Agent 上下文 ([#211](https://github.com/CherryHQ/stella/pull/211))
- **任务**：任务列表和创建操作现在需要显式指定 `agent_id`；新增 Agent 访问权限校验 ([#212](https://github.com/CherryHQ/stella/pull/212))

### ♻️ 重构
