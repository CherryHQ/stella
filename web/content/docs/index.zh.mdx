Stella 是一个长期与你一起工作的 AI 伙伴，不只是一个聊天 agent。你可以把她当作公司的同事、家庭的管家、私人的助手，或用于写作、编程、研究和运营的专门协作者。

Stella 从一开始就是多租户、多用户、多 agent 系统。每个 agent 都可以有自己的角色、工具、技能、定时任务、沙箱策略和工作区。每个用户和每个 agent 之间都有专门的记忆，因此 Stella 可以理解不同的人，而不是把所有人压成同一份画像。

你可以把 Stella 部署在自己选择的环境里，使用自己的模型 API 密钥，并从 Telegram、QQ、飞书、微信、Web UI 或终端与她对话。对话、密钥、记忆和工作区都由你掌控。

## 快速开始

```bash
# 安装
brew install CherryHQ/tap/stella

# 启动服务器 —— Web UI：http://localhost:25678
stella server
```
