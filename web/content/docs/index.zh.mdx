Stella 帮助组织创建共享的专业 AI Agent。业务负责人为 Agent 配置 instructions、skills、tools、knowledge 和记忆策略；其他人只需要像找同事一样聊天，把 goal 交给它，Stella 会把 goal 推进成可追踪的工作。

当团队需要一个可复用的专家时，就应该使用 Stella：财务 Agent 处理报销，HR Agent 处理内推和招聘，工程 Agent 处理代码审查和发布，研究 Agent 持续阅读并总结网页和 PDF。
