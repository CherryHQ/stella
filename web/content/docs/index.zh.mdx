Stella 是一个自托管的 AI 助手，能记住每一次对话，连接你常用的通讯渠道，并在你不在时替你工作。在你自己的机器上运行，使用你自己的 API 密钥，数据始终保存在本地。

## 快速开始

```bash
# 安装
brew install CherryHQ/tap/stella

# 启动服务器 —— 管理面板：http://localhost:25678
stella server
```
