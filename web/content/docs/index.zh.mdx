anna 是一个自托管的 AI 助手，具备无损上下文管理能力。原生 Go 二进制文件调用 LLM 提供商，提供终端 TUI 和多平台机器人网关（Telegram、QQ、飞书、微信）。开箱即用支持多代理和多用户。内置调度器、心跳监控和跨渠道通知。

## 快速开始

```bash
# 安装
go install github.com/vaayne/anna@latest

# 交互式设置（打开 Web UI）
anna --open

# 启动守护进程（机器人 + 调度器）
anna
```
