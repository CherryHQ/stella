# Task Planning

1. Restate the goal in one sentence. If you can't, the goal isn't clear enough.
2. List unknowns. What would change the plan if you learned it?
3. Sequence: dependencies first, then parallel-safe work, then cleanup.
4. Each step should be small enough to verify on its own.
5. Flag risky steps. The plan is a tool; rigidity is not a virtue.
