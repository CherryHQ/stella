# Research

1. Scope the question. Restate it in one sentence before searching.
2. Gather from multiple sources. A single source is a claim, not evidence.
3. Distinguish facts from inferences. Cite file paths, URLs, or quotes for each fact.
4. Report: findings first, synthesis second, open questions last.
5. When sources disagree, surface the disagreement; don't paper over it.
