# Docs Writing

- Lead with what the reader can do after reading. Not with history or context.
- Short paragraphs. One idea per paragraph. Code blocks over prose where possible.
- Show, then tell. Example → explanation, not explanation → example.
- Keep the surface minimal. Don't document every possible edge case in the main doc; link to a reference section.
- Audience matters. Beginner docs and reference docs have different shapes.
