## 重点问题

1. **P1: mixed_long 中 skill recall 不足。** 长对话里同时存在 world fact 和 reusable workflow 时，fact 线能抓到，但 skill 线容易不产候选。需要加强 skill generation 对 explicit reusable workflow / loaded skill delta 的识别，但不能放松 skill_negative 的保守边界。
2. **P2: world/project knowledge 路由仍不稳定。** `wsl_dev_environment` 应是 world/project knowledge，却被路由为 user。需要在 fact generation/evaluation 里更明确：Stella 项目开发环境、repo workflow、CLI/WSL setup 是 knowledge，而不是用户 profile。
3. **P3: user fact durability 仍偏宽。** 如购物频率、车险省钱、第三方名字/家人偏好等容易被 accepted。需要让 evaluator 对 current transaction、third-party detail、普通消费细节更低分，或在 generator 阶段更保守。
4. **P4: fact_user_positive 仍有 false negative。** `35a27287` 的语言学习/文化交流偏好没被提取。需要优化 user prompt，使“长期语言学习/练习偏好”在没有 remember wording 时也能被当作 durable profile。
5. **P5: provider 稳定性需要在 eval harness 层处理。** 全量主跑出现 2 个 transient provider error，单条重跑都通过。后续 harness 应支持 case-level retry，并把 retry 次数写入报告。
