---
title: Telegram Bot
---

anna には、ロングポーリング経由で動作する Telegram ボットが含まれています。Webhook や公開 IP は不要です。

## セットアップ

1. [@BotFather](https://t.me/BotFather) 経由でボットを作成し、ボットトークンを取得します
2. `anna onboard` を実行して管理パネルを起動します
3. 管理パネルで、AI プロバイダーを追加してから、ボットトークンを使用して Telegram チャンネルを設定します
4. ゲートウェイを起動します:

```bash
anna gateway
```

すべてのチャンネル設定（トークン、グループモード、許可された ID など）は管理パネルから管理されます。環境変数は、プロバイダー API キー（`ANTHROPIC_API_KEY`、`OPENAI_API_KEY`）と `ANNA_HOME` に制限されています。

## マルチユーザーサポート

各 Telegram ユーザーは、プラットフォーム ID から自動的に解決されます。セッションは、エージェントごとにユーザーごとにスコープされ、セッションキーは `{agentID}:tg:{userID}:{context}` の形式になります。手動でのユーザー設定は不要です。

## エージェントの切り替え

`/agent` コマンドを使用すると、ユーザーは利用可能なエージェント間で切り替えることができます:

- `/agent` -- 利用可能なすべてのエージェントを一覧表示
- `/agent <name>` -- 特定のエージェントに切り替え

DM では、ユーザーのデフォルトエージェントが設定されます。グループでは、グループ全体のアクティブなエージェントが設定されます。

## ストリーミングレスポンス

ボットは 2 つの戦略で LLM レスポンスをリアルタイムでストリーミングします:

### プライベートチャット: Draft API (Bot API 9.3+)

`sendMessageDraft` を使用して、レート制限の問題なしにスムーズなアニメーションストリーミングを実現します。API が利用できない場合は、自動的に編集モードにフォールバックします。

### グループチャット: Edit-in-Place

初期メッセージを送信し、トークンが到着するたびに定期的に（約 1 秒ごとに）編集します。ストリーミングメッセージは完了すると削除され、最終的なレスポンスが送信されます。

### ツールインジケーター

ツール実行中、ストリームは絵文字インジケーターでステータスを表示します:

| Tool     | Emoji            |
| -------- | ---------------- |
| `bash`   | lightning        |
| `read`   | book             |
| `write`  | pencil           |
| `edit`   | wrench           |
| `search` | magnifying glass |

## 画像サポート

ボットはプライベートチャットで写真メッセージを受け付けます。画像を送信すると:

1. ボットは Telegram のファイル API から最高解像度のバージョンをダウンロードします
2. MIME タイプを検出し、画像を base64 エンコードします
3. マルチモーダルメッセージ（画像 + オプションのキャプションテキスト）としてモデルに送信します
4. モデルは画像を分析し、テキストで応答します

使用例: スクリーンショットの説明、図の分析、写真から文書を読み取るなど。

モデルが画像を返す場合（例: ツール結果から）、テキストレスポンスの後に Telegram の写真として送信されます。

> **注意:** 画像サポートには、ビジョン対応モデル（例: Claude 3+、GPT-4o）が必要です。

## グループサポート

ボットは設定可能なレスポンス動作を持つグループチャットをサポートしています。管理パネルでグループモードを設定します:

- `mention` -- @メンション時のみ応答（デフォルト）
- `always` -- すべてのメッセージに応答
- `disabled` -- グループメッセージを完全に無視

## アクセス制御

管理パネルで許可されたユーザー ID を追加することで、ボットとやり取りできる Telegram ユーザーを制限します。空のままにするとすべてのユーザーを許可します。Telegram で `/whoami` コマンドを使用してユーザー ID を取得します。

## 通知

ボットは通知バックエンドとしても機能します。管理パネルでデフォルトの通知チャットとオプションのブロードキャストチャンネルを設定します。

使用用途:

- `notify` エージェントツール（ゲートウェイモード）
- スケジューラージョブ結果のブロードキャスト

完全な通知アーキテクチャについては、[notification-system.md](/docs/features/notification-system) を参照してください。

## モデルの切り替え

ユーザーは `/model` コマンドでトリガーされるインラインキーボードを使用して、会話中にモデルを切り替えることができます。モデルリストは、テキストフィルタリングサポート付きでページ分割されています。

## コマンド

| Command             | Description                                                                           |
| ------------------- | ------------------------------------------------------------------------------------- |
| `/start` or `/help` | ウェルカムとヘルプ                                                                    |
| `/new`              | 新しいセッションを開始                                                                |
| `/compact`          | 会話履歴を圧縮                                                                        |
| `/model`            | 利用可能なモデルを一覧表示                                                            |
| `/model <number>`   | 番号でモデルに切り替え                                                                |
| `/model <query>`    | 名前でモデルをフィルタリング                                                          |
| `/agent`            | 利用可能なエージェントを一覧表示                                                      |
| `/agent <name>`     | アクティブなエージェントを切り替え（DM ではユーザーデフォルト、チャットではグループ） |
| `/whoami`           | ユーザー ID を表示                                                                    |

## 設定リファレンス

以下のすべての設定は、`anna onboard` 管理パネルから管理されます。

| Field         | Description                                        | Default    |
| ------------- | -------------------------------------------------- | ---------- |
| `token`       | Bot API トークン                                   | (required) |
| `notify_chat` | プロアクティブ通知用のチャット ID                  |            |
| `channel_id`  | ブロードキャストチャンネル（@名前または数値 ID）   |            |
| `group_mode`  | グループ動作: `mention`、`always`、`disabled`      | `mention`  |
| `allowed_ids` | ボットの使用を許可されたユーザー ID（空 = すべて） | `[]`       |
