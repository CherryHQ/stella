## [0.16.0] - 2026-04-24

### ✨ 功能

- **插件**：新增运行时 manifest 工具插件 — 通过 `$ANNA_HOME/plugins.yaml` 支持文件驱动的 CLI 工具集成，含双层合并、二进制供应、基于版本的缓存和管理 UI ([#124](https://github.com/vaayne/anna/pull/124))
- **OAuth**：新增通用 OAuth 注册表/代理框架，集成至运行时、管理端和插件宿主路径；新增 OAuth 提供商的 manifest 校验 ([#125](https://github.com/vaayne/anna/pull/125))
- **插件**：将 `gh`、`lark-cli`、`tap-web` 和 `mise` 统一为一级 CLI 支持工具插件模式，含插件自有二进制、包装器、会话环境、捆绑技能及提示注册 ([#123](https://github.com/vaayne/anna/pull/123))

### ♻️ 重构

- **插件**：整合并简化嵌入式工具和包管理内部逻辑；移除旧版 OAuth 包和未使用的 vault/token 管理代码 ([#125](https://github.com/vaayne/anna/pull/125))
- **认证**：将旧版认证行迁移至 `tool/gh` 和 `tool/lark-cli` 插件；移除旧认证插件包 ([#123](https://github.com/vaayne/anna/pull/123))

**完整变更日志**：[v0.15.0...v0.16.0](https://github.com/vaayne/anna/compare/v0.15.0...v0.16.0)

## [0.15.0] - 2026-04-22

### ✨ 功能

- **密钥库**：新增基于 age 信封加密的用户私密存储，密钥在沙盒会话中自动注入为环境变量 ([#120](https://github.com/vaayne/anna/pull/120))
- **凭据**：统一凭据工具与共享后端服务 ([#122](https://github.com/vaayne/anna/pull/122))
- **OAuth**：为 gh 和 lark-cli 新增设备流 OAuth 认证 ([#121](https://github.com/vaayne/anna/pull/121))
- **工具**：将 GitHub CLI（`gh`）加入预构建沙盒工具包
- **管理界面**：重新设计插件页面，新增标签页导航，拆分账户与凭据 UI

### ⚠️ 破坏性变更

- **沙盒**：移除 `boxsh` 后端 — Docker 现在是唯一的沙盒后端。升级前请安装并启动 Docker Desktop（macOS/Windows）或 Docker 守护进程（Linux）。配置文件中设置 `sandbox.backend = "boxsh"` 的用户，系统将自动将其重新映射并输出一次性日志警告。

### ✨ 改进

- **stdio MCP**：`StartProcess`（stdio MCP 服务器）现在在每次运行时均可正常工作。此前在 `boxsh` 会话中静默失败；Docker 的容器模型为每个会话提供了独立的进程命名空间，stdio MCP 服务器可稳定启动。

### ♻️ 重构

- **沙盒**：简化为仅 Docker 后端 ([#118](https://github.com/vaayne/anna/pull/118))
- **构建**：构建前同步嵌入依赖和系统技能 ([#119](https://github.com/vaayne/anna/pull/119))
- **认证**：将认证配置与密钥库解耦，合并 oauthcli 到凭据模块

### ✅ 测试

- 加强重构覆盖率
