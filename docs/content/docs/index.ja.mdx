anna はロスレスなコンテキスト管理を備えたセルフホスト型 AI アシスタントです。ネイティブ Go バイナリで LLM プロバイダーを呼び出し、ターミナル TUI とマルチプラットフォームボットゲートウェイ（Telegram、QQ、Feishu）を提供します。複数のエージェントと複数のユーザーをすぐに使用できます。スケジューラー、ハートビート監視、クロスチャネル通知を内蔵。

## クイックスタート

```bash
# インストール
go install github.com/vaayne/anna@latest

# インタラクティブセットアップ（Web UI を開く）
anna onboard

# チャットを開始
anna chat

# またはデーモンを起動（ボット + スケジューラー）
anna gateway
```
