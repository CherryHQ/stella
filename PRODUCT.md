# Product

## Register

product

## Users

Self-hosters and small teams running their own AI assistant. Technical users who manage agents, monitor sessions, configure providers, and actively chat through multiple channels (terminal, Telegram, QQ, Feishu, WeChat). The admin panel is a power-user surface for observability, debugging, and direct interaction with agents.

## Product Purpose

Anna is a self-hosted AI assistant with persistent memory (LCM), multi-agent support, multi-channel messaging, and a scheduler. The web admin panel provides session inspection, agent configuration, workspace file management, and real-time chat with agents. Success: the admin panel feels like a capable IDE-adjacent tool, not a consumer chat app.

## Brand Personality

Calm, precise, competent. A quiet professional tool that gets out of the way. Editorial restraint over feature density.

## Anti-references

- Slack: too busy, too many notifications, too much visual noise
- ChatGPT web: too simplified, hides power-user controls
- Corporate dashboards with 20 tabs and dense metric grids
- Generic SaaS admin panels with card-heavy layouts

## Design Principles

1. Show the work: surface agent actions, tool calls, and memory operations transparently.
2. Density with clarity: fit information without clutter. Monospace metadata, compact rows, generous whitespace where it matters.
3. Three-surface thinking: sidebars for navigation, center for content, panels for context. Each surface has a distinct role.
4. Quiet confidence: no decoration for decoration's sake. Hairlines, tinted neutrals, and typography carry the hierarchy.

## Accessibility & Inclusion

WCAG AA minimum. Respect prefers-reduced-motion. Light and dark theme support (already implemented via CSS custom properties).
